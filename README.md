# Dev SENAI

Repositório destinado aos projetos e atividades desenvolvidos durante o curso no SENAI.

## Organização

| Pasta | Conteúdo |
|---|---|
| `primeiro-termo/` | Projetos, exercícios e atividades do primeiro termo. |
| `segundo-termo/` | Projetos, exercícios e atividades do segundo termo. |

Cada projeto pode ser colocado em sua própria subpasta, com um README explicando seu objetivo, tecnologias utilizadas e instruções para execução.

## Estrutura inicial

```text
dev-senai/
├── primeiro-termo/
│   └── README.md
├── segundo-termo/
│   └── README.md
└── README.md
```

## Observação

Este repositório contém exclusivamente materiais e projetos escolares.
