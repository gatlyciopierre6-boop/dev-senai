# Dev SENAI

Repositório criado para organizar os projetos e atividades desenvolvidos durante as aulas do curso no SENAI.

## Sobre o repositório

Aqui estão reunidos os materiais escolares do **primeiro termo** e do **segundo termo**, separados em suas respectivas pastas para facilitar a consulta e a continuidade dos estudos.

> Este repositório contém exclusivamente projetos, exercícios e atividades escolares.

## Organização dos projetos

| Pasta | Conteúdo |
|---|---|
| [`primeiro-termo/`](./primeiro-termo) | Aulas, exercícios e projetos desenvolvidos no primeiro termo. |
| [`segundo-termo/`](./segundo-termo) | Aulas, exercícios e projetos desenvolvidos no segundo termo. |

## Tecnologias estudadas

Os projetos podem utilizar diferentes tecnologias trabalhadas durante o curso, como **Python**, **HTML**, **CSS**, **JavaScript**, bancos de dados e outras ferramentas de desenvolvimento.

## Como navegar

Para acessar os projetos de um termo, entre na pasta correspondente. Dentro dela, os arquivos estão organizados de acordo com as aulas, atividades e projetos realizados.

## Objetivo

Manter um histórico organizado da evolução dos conhecimentos adquiridos no curso e facilitar a visualização dos projetos desenvolvidos ao longo dos termos.
