## Sobre o projeto

Este repositório reúne as atividades desenvolvidas durante o segundo termo do curso de Desenvolvimento de Software. A organização por disciplina e aula torna possível navegar pelos exercícios de forma progressiva, consultar soluções anteriores e acompanhar a construção de uma base para projetos web e aplicações de backend.

A experiência abaixo foi pensada para funcionar como um pequeno painel de estudos: você pode abrir somente a seção que deseja, acessar os arquivos diretamente ou seguir o roteiro recomendado de execução.

## Comece aqui

### Pré-requisitos

Instale o **Node.js em uma versão LTS** e o **npm** para executar os exercícios de Backend. Para abrir os projetos HTML usando um servidor local, utilize o **Python 3**. O **MySQL** e uma ferramenta compatível com **brModelo** são opcionais e necessários apenas para as atividades de banco de dados e modelagem.

### Instalação

```bash
git clone https://github.com/gatlyciopierre6-boop/2-TERMO.git
cd 2-TERMO
cd BACKEND
npm install
```

### Roteiro rápido

| Quero... | Execute ou abra |
| --- | --- |
| Rodar o exercício de vendas | `node JAVA.SCRIPT/AULA1/app5.js` |
| Calcular o IMC | `node JAVA.SCRIPT/AULA2/imc.js` |
| Executar a atividade final | `node JAVA.SCRIPT/AULA3/aula_autonoma/atividade_final.js` |
| Abrir o DevSolutions | [`LIMA/HTML/AULA02/DevSolutions/index.html`](https://github.com/gatlyciopierre6-boop/2-TERMO/blob/main/LIMA/HTML/AULA02/DevSolutions/index.html) |
| Conferir o script SmartCoffee | [`SMARTCOFFEE_FISICO.sql`](https://github.com/gatlyciopierre6-boop/2-TERMO/blob/main/BANCO%20DE%20DADOS/MySQL/AULA2/SMARTCOFFEE_FISICO.sql) |

> Os programas de JavaScript que usam `readline-sync` são interativos e aguardam respostas no terminal. Execute-os em um shell interativo para acompanhar as perguntas e os resultados.

## Principais aprendizados

O termo registra a passagem dos primeiros exercícios de marcação para aplicações de terminal e atividades de modelagem de dados. Entre as práticas estão a construção de páginas, aplicação de estilos, manipulação de entradas, validação de informações, criação de menus, uso de dependências npm e elaboração de estruturas relacionais.
