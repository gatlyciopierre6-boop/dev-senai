# Glossário de Termos Técnicos: Sistemas Operacionais

Este glossário reúne os principais conceitos técnicos abordados nas aulas de Sistemas Operacionais e Fundamentos de TI. Ele serve como uma referência rápida para o dia a dia, permitindo que o aluno consulte definições precisas sem precisar reler todo o material didático.

---

## A - C

O **Active Directory (AD)** é um serviço de diretório desenvolvido pela Microsoft, amplamente utilizado em ambientes corporativos baseados em Windows Server. Sua função principal é gerenciar permissões de usuários, computadores e políticas de grupo em uma rede centralizada.

O **Bash (Bourne Again Shell)** é o interpretador de comandos (terminal) padrão na maioria das distribuições Linux. Ele é extremamente poderoso para a automação de tarefas e manipulação de arquivos.

A **CLI (Command Line Interface)** refere-se à Interface de Linha de Comando. É o ambiente textual onde o usuário digita instruções para interagir com o computador, substituindo o uso do mouse e das janelas gráficas.

O **CMD (Command Prompt)** é o terminal padrão e mais antigo do sistema operacional Windows.

O **Código-fonte (Source Code)** representa o conjunto de instruções escritas por programadores (em linguagens como Python, C++ ou Java) que formam um software. No ecossistema *Open Source*, esse código é disponibilizado publicamente.

## D - F

**DevOps (Development and Operations)** é uma cultura e um conjunto de práticas que integra o desenvolvimento de software com a administração de sistemas (operações), focando fortemente na automação de processos.

A **Distribuição Linux (Distro)** é uma versão empacotada do sistema operacional Linux, que inclui o núcleo (kernel), um ambiente gráfico e programas pré-instalados. Exemplos populares incluem Ubuntu, Debian e Fedora.

Os **Drivers (Controladores)** são pequenos programas que ensinam o Sistema Operacional a se comunicar corretamente com uma peça de hardware específica, como uma placa de vídeo ou uma impressora.

O **Firewall** é um sistema de segurança que monitora e controla o tráfego de rede de entrada e saída com base em regras predefinidas, atuando como uma barreira protetora contra acessos não autorizados.

A **GUI (Graphical User Interface)** é a Interface Gráfica de Usuário, composta pelo visual que vemos na tela (ícones, janelas, menus e botões), permitindo a interação intuitiva com o computador através do mouse.

## H - M

O **Kernel (Núcleo)** é a parte mais interna e vital do Sistema Operacional. Ele atua como o "cérebro" da máquina, controlando diretamente o hardware (CPU e memória RAM) e ditando as regras de execução para os programas.

O **Malware** é a abreviação de "Malicious Software" (Software Malicioso). É um termo abrangente para qualquer programa criado com a intenção de causar danos, roubar dados sensíveis ou espionar as atividades do usuário.

Um sistema **Multiusuário** possui a capacidade de permitir que várias pessoas criem suas próprias contas independentes, cada uma com seus arquivos pessoais, senhas e configurações, compartilhando o mesmo computador.

## N - P

O **NTFS (New Technology File System)** é o sistema de arquivos padrão utilizado pelo Windows. Ele é responsável por organizar como os dados são armazenados e é conhecido por suportar permissões de segurança avançadas.

**Open Source (Código Aberto)** é um modelo de desenvolvimento de software onde o código-fonte é disponibilizado gratuitamente para que qualquer pessoa possa ler, modificar e melhorar o programa.

O **Princípio do Privilégio Mínimo** é uma regra de segurança fundamental na administração de sistemas. Ele dita que qualquer usuário ou programa deve ter acesso apenas às informações estritamente necessárias para desempenhar sua função, e nada mais.

Um software **Proprietário** (como o Windows) é aquele cujo código-fonte é fechado e pertence exclusivamente a uma empresa, exigindo a compra de uma licença comercial para seu uso.

## R - S

O **Ransomware** é um tipo extremamente perigoso de malware que "sequestra" os dados do computador (criptografando os arquivos) e exige o pagamento de um resgate, geralmente em criptomoedas, para que os dados sejam devolvidos.

No mundo Linux, um **Repositório** funciona como um "armazém" centralizado na internet de onde o usuário pode baixar e instalar softwares com segurança, utilizando o terminal.

Um **Script (Roteiro)** é um arquivo de texto simples que contém uma sequência de comandos de terminal. Ao executar o script, o computador realiza todas aquelas tarefas automaticamente, uma após a outra, economizando tempo.

O **Sistema Operacional (S.O.)** é o programa principal que gerencia todo o computador. Ele atua como a ponte (ou tradutor) entre o hardware (as peças físicas) e os aplicativos que utilizamos no dia a dia.

O **SSH (Secure Shell)** é um protocolo de rede seguro utilizado para acessar e controlar computadores remotamente, sendo uma ferramenta essencial para administradores de servidores Linux.

## T - Z

O **Terminal** é outro nome comum para a CLI (Interface de Linha de Comando), referindo-se à janela onde os comandos são digitados.

Um **Trojan (Cavalo de Troia)** é um malware que se disfarça dentro de um programa aparentemente legítimo (como um jogo gratuito) para enganar o usuário e infectar o sistema sem que ele perceba.

Uma **Variável (de Ambiente)** é um espaço na memória do computador onde o Sistema Operacional ou um script armazena informações temporárias (como textos ou números) para que sejam utilizadas em etapas posteriores da execução.

Um **Vírus** é um malware clássico, mas ainda perigoso, que precisa "se anexar" a um arquivo executável para se espalhar e se multiplicar automaticamente toda vez que o usuário abre o arquivo infectado.
