# 🖥️ Sistemas Operacionais e Fundamentos de TI

Bem-vindo ao repositório de **Sistemas Operacionais e Fundamentos de TI**! Este espaço reúne todo o material didático, anotações e projetos práticos desenvolvidos ao longo da disciplina. 

Aqui você encontrará uma jornada completa, desde a compreensão do papel do sistema operacional na gestão de hardware, passando pela operação de ambientes gráficos e de linha de comando, até a automatização de tarefas e princípios fundamentais de segurança cibernética.

## 📚 Estrutura do Repositório

O conteúdo está organizado por aulas para facilitar a navegação e o estudo:

| Arquivo | Aula | Tema Principal |
| :--- | :--- | :--- |
| **Aula_01_Introducao_Linux.md** | Aula 01 | Introdução aos S.O. e Distribuições Linux |
| **Aula_02_Windows_GUI.md** | Aula 02 | Operação e Configuração do Windows (GUI) |
| **Aula_03_CLI_Commands.md** | Aula 03 | Operação via CLI (CMD e Bash) |
| **Aula_04_Automatizacao_Scripts.md** | Aula 04 | Automatização e Variáveis de Ambiente |
| **Aula_05_Seguranca_Cibernetica.md** | Aula 05 | Fundamentos de Segurança Cibernética |
| **Glossario.md** | Extra | Dicionário de termos técnicos |

## 🎯 Objetivo de Aprendizagem

Ao final deste módulo, espera-se que o aluno seja capaz de:
1. Compreender a arquitetura básica de um sistema operacional e seu papel como intermediário entre o hardware e o software.
2. Administrar eficientemente ambientes Windows e Linux (Ubuntu, Debian, Fedora).
3. Navegar e gerenciar arquivos utilizando a Interface de Linha de Comando (CLI) em Windows (CMD) e Linux (Bash).
4. Criar scripts básicos para automatizar tarefas repetitivas.
5. Aplicar princípios fundamentais de segurança da informação, como firewalls e controle de privilégios.
