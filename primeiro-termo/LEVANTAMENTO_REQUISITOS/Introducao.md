# 📋 Engenharia e Levantamento de Requisitos

## 📅 Conteúdo das Aulas

### 🔹 Aula 01: Conceitos Iniciais e Fundamentos
*   **O que é Requisito:** Necessidades, condições ou capacidades que um software deve atender.
*   **Importância do Levantamento:** Evitar retrabalho e alinhar expectativas do projeto.

### 🔹 Aula 02: Requisitos Funcionais vs. Não-Funcionais
*   **Requisitos Funcionais (RF):** O que o sistema deve fazer (Ex: permitir o cadastro de novos usuários).
*   **Requisitos Não-Funcionais (RNF):** Como o sistema deve se comportar (Ex: carregar as páginas em menos de 2 segundos).

### 🔹 Aula 03: Técnicas de Elicitação - Entrevistas e Brainstorming
*   **Entrevistas:** Conversas diretas com stakeholders para entender o negócio.
*   **Brainstorming:** Reunião criativa em equipe para extrair ideias e soluções sem julgamentos.

### 🔹 Aula 04: Técnicas de Elicitação - Prototipagem
*   **Baixa Fidelidade:** Desenhos em papel ou wireframes simples (foco na estrutura).
*   **Alta Fidelidade:** Protótipos digitais interativos (foco na experiência do usuário).

### 🔹 Aula 05: Modelagem com Diagramas
*   **Diagramas de Casos de Uso:** Mapeamento visual de quem usa o sistema (Atores) e o que eles fazem.

### 🔹 Aula 06: Engenharia de Requisitos para Relatórios
*   **Definição de Saídas:** Levantamento de dados necessários para tomada de decisão (filtros, campos e formatos como PDF/Excel).
