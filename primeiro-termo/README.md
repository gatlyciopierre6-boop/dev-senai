### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Books.png" alt="Sobre" width="25" height="25" /> Sobre o Repositório

Este repositório centraliza todo o material didático, exercícios práticos e projetos desenvolvidos durante o primeiro termo do curso técnico no SENAI e SESI. O foco principal é a aquisição de fundamentos sólidos em desenvolvimento de sistemas, IoT e segurança cibernética.

Aqui, documentamos o caminho de aprendizagem desde a definição de requisitos de software até a implementação de lógicas de automação e protocolos de comunicação para dispositivos inteligentes.

```
Primeiro_termo/
├── ARQUITETURA_IOT/        # Fundamentos de IoT, sensores e protocolos de comunicação
├── LEVANTAMENTO_REQUISITOS/# Documentação e padronização de requisitos funcionais e não funcionais
├── LOGICA_PROGRAMAÇA/      # Exercícios de lógica algorítmica e a Calculadora Web 2.0
└── SISTEMAS_OPERACIONAIS/  # Administração de Windows, Linux (CLI), scripting e segurança cibernética
```
